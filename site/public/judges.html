The test

Three steps, one optional.

Everything here runs in your browser. As a guest, the agent run is a replay of a real recorded H Company session.

  1. Open the demo company

    You land on ACME Conseil, a demo company, with savings already found.

    • Every euro comes from the deterministic engine; Holo only labels transactions.
    • "Needs you" lists what Kerdaxis wants you to decide.
    • The five-value ledger shows that nothing is confirmed yet.
    Open the demo

  2. Cancel Nuvio CRM with H Company

    Click "Cancel with H Company" on Nuvio CRM, a fictional supplier we built, and approve.

    • The agent declines the retention offer and ignores an instruction injected in the page.
    • It stops before the irreversible button. Nothing happens until you give the green light.
    • Kerdaxis then compares the confirmation number read by the agent with the one on the portal.

  3. Check how it is built

    The home page explains the harness and shows the measured runs, including the one that failed.

    • Under the hood: two-turn mission, watchdog, domain lock, path research.
    • Proof: 5/5 cancellations confirmed by the Stripe API, 2/2 refusals respected.
    Under the hood

  4. Optional: run the live agent

    With the test access (ask the team), sign in to launch a real H Company agent on our demo portal, or on Stripe's real customer portal in test mode. One live agent runs at a time: if it is busy, use the replay.
