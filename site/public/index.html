Under the hood

How Kerdaxis drives H Company's Computer Use agents.

The stop before the irreversible click does not rely on the model behaving. The harness enforces it.

  1. A two-turn mission

    Turn one ends on the final confirmation page. The irreversible click belongs to turn two, which starts only after your green light.

  2. A watchdog outside the model

    When the final confirmation page shows up, Kerdaxis pauses the H session through the API, whatever the model decides. A done page seen without approval cuts the session and flags it.

  3. One domain, page text as data

    Navigation is limited to the approved supplier domain. Text on the page is read as data, never as instructions.

  4. Path research before acting

    Each supplier's cancellation path is written by hand or researched in its official docs, with Linkup and an H agent reading screenshots. If research fails, a generic brief takes over.

  5. Confirmed by the supplier

    Cancelled only when the supplier says so: the same number on its portal, or the subscription state read from Stripe. One session per approval, with an idempotency key.

  6. Holo for every language call

    Categorization, letters, price extraction and supplier risk run on H Company's Holo models, after a PII filter. The euros come from the deterministic engine.

Run 1, demo portal: it didn't stop.

The agent clicked through the confirmation without pausing. That is exactly the failure an approval step exists to prevent, so we made the stop structural.

The fix: a stop in three layers

  1. Two-turn mission. The first turn ends at the confirmation page; the second starts only after approval.
  2. Automatic pause. Kerdaxis halts the run itself when the confirmation page appears.
  3. Human green light. Required to continue. Voice can't give it.

Since the fix

On Stripe’s real portal the agent stopped at the final button in all 7 runs, after about 24 s. With the green light it confirmed, and the Stripe API showed the subscription cancelled. Without it, the subscription stayed active.

Questions

What finance teams ask first.

Can Kerdaxis move money?

No. It reads your Qonto account through MCP in read-only mode, and every write tool is blocked. It cannot pay, transfer or create a card.

What if the agent gets it wrong?

It stops before every irreversible step and waits for your green light. A cancellation counts only when the supplier confirms it. Our proof section shows the run that failed and how we fixed it.

Which suppliers does it work with today?

Live runs work on our demo supplier portal and on Stripe's real customer portal, in test mode. New suppliers are added one by one, each with a researched cancellation path and a verifier.

Where does my data go?

The app runs on Cloudflare with its database in Western Europe, and bank tokens are stored encrypted. Web searches only ever receive a merchant name and a category: no IBAN, no transaction ID, no personal data.

How much does it cost?

The demo is free, with no signup. The live agent on our demo portals is 5 € a month, in Stripe test mode, so no real charge. Accounting firms start with a pilot.
