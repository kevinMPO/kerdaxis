Step 05 · Execute, up close

It does the clicking. You approve the click that matters.

Kerdaxis hands each cancellation to an H Company computer-use agent. It works on the supplier's own portal the way a person would, and stops where a person should.

The agent reads the screen and acts on it: it clicks, types and scrolls through the supplier's pages. Kerdaxis sets the limits it works within.

  • A human before anything irreversibleThe run pauses. Only your green light resumes it.

Run 1, demo portal: it didn't stop.

The agent clicked through the confirmation without pausing. That is exactly the failure an approval step exists to prevent, so we made the stop structural.

The fix: a stop in three layers

  1. Two-turn mission. The first turn ends at the confirmation page; the second starts only after approval.
  2. Automatic pause. Kerdaxis halts the run itself when the confirmation page appears.
  3. Human green light. Required to continue. Voice can't give it.

Since the fix

On Stripe’s real portal the agent stopped at the final button in all 7 runs, after about 24 s. With the green light it confirmed, and the Stripe API showed the subscription cancelled. Without it, the subscription stayed active.
