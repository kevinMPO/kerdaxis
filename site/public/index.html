Run 1: it didn't stop.

The agent clicked through the confirmation without pausing. That is exactly the failure an approval step exists to prevent, so we made the stop structural.

The fix: a stop in three layers

  1. Two-turn mission. The first turn ends at the confirmation page; the second starts only after approval.
  2. Automatic pause. Kerdaxis halts the run itself when the confirmation page appears.
  3. Human green light. Required to continue. Voice can't give it.

Since the fix

The agent stops and waits. While it waits, the portal still shows the subscription as active. After the green light it confirms, and the portal returns the same confirmation number the agent read.

Before the agent moves, the numbers are already checked.

The agent is the last step. Everything before it is read-only, deterministic and sourced.

Read-only access
